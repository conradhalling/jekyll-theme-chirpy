I want to build a web application with a backend database, and I think I
want to try using PHP. I haven't used PHP since 2005, when I was a freelance
bioinformatics developer.

Since I am a book-oriented learner, I looked for good books that teach PHP. I
want a book that will introduce me to PHP without having to teach me the basics
of programming.

## Building Secure PHP Applications

<cite>[Building Secure PHP Applications: A Comprehensive Guide to Protecting Your Web Applications from Threats](https://link.springer.com/book/10.1007/979-8-8688-0932-3)</cite><br>
by Satej Kumar Sahu<br>
Apress<br>
418 pp.<br>
November 18, 2024<br>

This book is available in digital format. This book looks very useful to me.

## An Introduction to PHP

<cite>[An Introduction to PHP: Learn PHP 8 to Create Dynamic Websites](https://link.springer.com/book/10.1007/979-8-8688-0177-8)</cite><br>
by Mark Simon<br>
Apress<br>
625 pp.<br>
March 7, 2024<br>

This book is available in digital form, and the source code is available
from a git repository. The book is more basic than I want.

## Learn PHP 8

<cite>[Learn PHP 8: Using MySQL, JavaScript, CSS, and HTML5](https://link.springer.com/book/10.1007/978-1-4842-6240-5)</cite><br>
by Steve Prettyman<br>
Apress<br>
426 pp.<br>
October 5, 2020<br>

This book is a little old, and it's too basic for my needs.

## PHP & MySQL

<cite>[PHP & MySQL: Server-side Web Development](https://phpandmysql.com)</cite><br>
by Jon Duckett<br>
Wiley<br>
668 pp.<br>
January 12, 2022<br>

This is book is highly recommended by users in the PHP subreddits on
[reddit.com](https://reddit.com/)
as being a modern presentation of PHP rather than a revision of an old book with
outdated code. I plan to order this book.

## PHP 8 Basics

by Gunnard Engebreth, Satej Kumar Sahu<br>
Apress<br>
329 pp.<br>
December 28, 2022<br>

This book is more basic than I want.
